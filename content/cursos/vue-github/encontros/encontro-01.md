Neste encontro vamos criar a base da aplicação que será usada nos exercícios. A ideia é entender o caminho completo: criar o projeto, reconhecer os arquivos importantes e fazer a interface reagir aos dados.

## O que vamos construir

Uma pequena aplicação de lista de tarefas, começando por um componente de boas-vindas e evoluindo para um contador e uma lista com formulário.

## Antes de começar

- Tenha o ambiente da etapa de preparação funcionando.
- Abra o VS Code na pasta do projeto.
- Deixe o terminal integrado visível: vamos usá-lo bastante.

## Criando o projeto

```bash
npm create vue@latest meu-app
cd meu-app
npm install
npm run dev
```

Durante a criação, aceite TypeScript e Vue Router. Os demais recursos são opcionais para o minicurso.

> O título e os tópicos deste encontro seguem o planejamento preliminar do minicurso e podem mudar. O texto e os exemplos desta página são demonstrativos.
