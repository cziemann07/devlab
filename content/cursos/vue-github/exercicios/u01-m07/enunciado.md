**Trilha:** v-if · v-else · **Tempo sugerido:** 7–9 min · **Etapa:** Progressão.

**Situação-problema.** Uma pizzaria fechada não deveria mostrar a mesma mensagem de uma aberta.

**Antes de mexer.** Qual é a mensagem inicial? O que muda após clicar? Escreva uma previsão em uma frase.

**Seu desafio.** Mostre “Aceitando pedidos” com `v-if` e “Fechado por enquanto” com `v-else`.

**Primeira pista (abra só se necessário).** Use a variável booleana `aberto` como condição.

**Perguntas de investigação.** Você precisa de duas telas ou de duas possibilidades na mesma tela? Como o aluno saberia que uma lista de tarefas está vazia?

**Transferência para outro contexto.** Na To-Do List, use `v-if` para exibir “Nenhuma tarefa cadastrada”.

**O que conta como conquista?** A mensagem corresponde ao valor de `aberto`. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
