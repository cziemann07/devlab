**Trilha:** computed · valores derivados · **Tempo sugerido:** 8–10 min · **Etapa:** Progressão.

**Situação-problema.** Como manter o preço total correto sempre que a quantidade mudar?

**Antes de mexer.** Ao pedir três pizzas de R$ 35, qual deve ser o total? Escreva uma previsão em uma frase.

**Seu desafio.** Crie `total = computed(...)`, importe `computed` e mostre o resultado formatado.

**Primeira pista (abra só se necessário).** Lembre-se: no `<script setup>`, refs são lidos com `.value`.

**Perguntas de investigação.** Quem deveria alterar o total: a pessoa usuária ou a aplicação? Por que `total` é melhor como valor derivado do que como um segundo estado editável?

**Transferência para outro contexto.** Na To-Do List, que valor poderíamos calcular automaticamente a partir de uma lista?

**O que conta como conquista?** O total acompanha toda mudança de quantidade. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
