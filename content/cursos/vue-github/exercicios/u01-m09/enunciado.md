**Trilha:** @click · v-bind/:class · **Tempo sugerido:** 7–9 min · **Etapa:** Progressão.

**Situação-problema.** Como deixar visualmente claro que uma pizza foi selecionada?

**Antes de mexer.** Qual cor o botão deve ter antes e depois do clique? Escreva uma previsão em uma frase.

**Seu desafio.** Use `:class` para aplicar `ativo` somente quando `escolhido` for verdadeiro.

**Primeira pista (abra só se necessário).** A sintaxe de objeto pode ser `:class="{ ativo: escolhido }"`.

**Perguntas de investigação.** O estilo muda sem que tenhamos escrito duas páginas? O que seria inadequado em confiar apenas na cor como sinal de seleção?

**Transferência para outro contexto.** Na To-Do List, destaque visualmente tarefas concluídas.

**O que conta como conquista?** O botão alterna a classe e o texto informa seu estado. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
