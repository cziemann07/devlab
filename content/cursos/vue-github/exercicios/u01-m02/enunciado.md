**Trilha:** CSS3 · estilos com escopo · **Tempo sugerido:** 6–8 min · **Etapa:** Núcleo.

**Situação-problema.** Uma página funciona, mas é difícil saber onde começa e termina o pedido. Como melhorar?

**Antes de mexer.** O botão terá destaque? O cartão terá limites visuais? Escreva uma previsão em uma frase.

**Seu desafio.** Complete o estilo da classe `.cartao` com fundo, borda e arredondamento e ajuste o espaçamento do parágrafo.

**Primeira pista (abra só se necessário).** Experimente `background`, `border`, `border-radius` e `margin-bottom`.

**Perguntas de investigação.** Duas pessoas acharão o botão igualmente fácil de localizar? Qual parte depende de CSS e qual dependeria de JavaScript?

**Transferência para outro contexto.** Aplique o mesmo raciocínio visual à tarefa pendente de uma To-Do List.

**O que conta como conquista?** As mudanças visuais aparecem, sem alteração da lógica. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
