Atividade complementar adaptada do ZIP recebido.

1. Crie um array reativo de tarefas.
2. Liste os itens com `v-for` e `:key` estável.
3. Use `v-model` para digitar e adicionar uma tarefa.
4. Ignore campos vazios ou com apenas espaços e limpe o campo depois de adicionar.
5. Confira que adicionar um item não substitui os anteriores.

O playground mostra uma referência que também permite marcar e remover itens.
