Crie um componente que cumprimente a pessoa usuária pelo nome. O componente já existe no código inicial, mas a saudação ainda é fixa.

O campo de texto deve atualizar a saudação em tempo real. Quando o campo estiver vazio, use `pessoa` como valor padrão.

## O que observar

- O estado do nome precisa ser reativo.
- A saudação pode ser derivada do nome com `computed`.
- O template não deve repetir a regra de valor padrão.
