**Trilha:** Vue 3 · ref · v-model · **Tempo sugerido:** 7–9 min · **Etapa:** Núcleo.

**Situação-problema.** Como mostrar o nome do cliente enquanto ele digita, sem clicar em Enviar?

**Antes de mexer.** O que aparece quando o campo está vazio? O que muda ao digitar? Escreva uma previsão em uma frase.

**Seu desafio.** Conecte o campo à variável `nome` usando `v-model` e teste mudanças na prévia.

**Primeira pista (abra só se necessário).** O `ref` guarda o dado; `v-model` faz a ligação com o campo.

**Perguntas de investigação.** Qual parte controla o valor que aparece no parágrafo? O que o Vue faz quando você apaga o texto? E por que o nome não exige atualização da página?

**Transferência para outro contexto.** Na To-Do List, use `v-model` no campo de nova tarefa.

**O que conta como conquista?** A saudação acompanha a digitação e mostra “visitante” quando vazio. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
