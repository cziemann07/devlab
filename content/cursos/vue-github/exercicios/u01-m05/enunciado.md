**Trilha:** @click · funções · ref · limites · **Tempo sugerido:** 8–10 min · **Etapa:** Progressão.

**Situação-problema.** E se uma pessoa clicar no botão de diminuir até a quantidade ficar negativa?

**Antes de mexer.** Em qual valor a contagem começará? Qual seria o menor valor aceitável? Escreva uma previsão em uma frase.

**Seu desafio.** Corrija `aumentar` e `diminuir` para respeitarem o intervalo de 1 a 10 e desabilite botões nos limites.

**Primeira pista (abra só se necessário).** Use `if` dentro das funções e `:disabled` no template.

**Perguntas de investigação.** O código atual permite valores inválidos? Por que validar o valor na função, além de desabilitar o botão?

**Transferência para outro contexto.** Uma tarefa vazia também precisa de validação; onde colocaríamos essa regra?

**O que conta como conquista?** Os cliques não geram valores fora de 1 a 10. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
