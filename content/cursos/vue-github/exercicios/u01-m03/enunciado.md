**Trilha:** JavaScript · interpolação · **Tempo sugerido:** 6–8 min · **Etapa:** Núcleo.

**Situação-problema.** Duas pizzas custam mais que uma. Como mostrar isso na tela sem escrever o total manualmente?

**Antes de mexer.** Qual total deve aparecer para R$ 35 e quantidade 2? Escreva uma previsão em uma frase.

**Seu desafio.** Exiba preço unitário e total com expressões JavaScript dentro da interpolação do template.

**Primeira pista (abra só se necessário).** Lembre-se: `preco * quantidade`; `toFixed(2)` apresenta duas casas.

**Perguntas de investigação.** O valor 70 surge de uma conta ou de um texto fixo? Se mudar a constante `quantidade` para 3 e executar novamente, o que acontece? Isso já é interatividade em tempo de uso?

**Transferência para outro contexto.** Na To-Do List, que contagem poderia ser calculada a partir do tamanho de uma lista?

**O que conta como conquista?** Preço e total corretos aparecem após executar o código. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
