Desafio complementar adaptado para a trilha. Desenvolva no projeto local; o playground fornece uma referência em arquivo único.

## O que fazer

1. Crie pelo menos dois componentes em um projeto local.
2. Passe informações usando props.
3. Adicione estilos próprios e registre um commit.

## Confira

Teste os estados vazios e as interações. Registre um commit descritivo após conferir o resultado. A marcação de conclusão no DevLab é manual.
