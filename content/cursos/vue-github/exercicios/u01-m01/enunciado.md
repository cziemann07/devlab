**Trilha:** HTML5 · semântica · **Tempo sugerido:** 5–7 min · **Etapa:** Núcleo.

**Situação-problema.** Como alguém sabe qual campo deve preencher para pedir uma pizza?

**Antes de mexer.** Você vê um título e uma descrição, mas ainda não existe um campo de identificação. Escreva uma previsão em uma frase.

**Seu desafio.** Crie uma seção de pedido com `<h2>`, `<label for="cliente">` e `<input id="cliente">`.

**Primeira pista (abra só se necessário).** O `for` do rótulo precisa combinar com o `id` do campo.

**Perguntas de investigação.** O HTML atual mostra um formulário completo? Por que um campo com rótulo é melhor do que um campo identificado apenas pelo placeholder?

**Transferência para outro contexto.** Na To-Do List, troque o campo de cliente pelo campo de título da tarefa.

**O que conta como conquista?** Um campo associado a um rótulo aparece e é identificável. Explique o caminho para outra pessoa, mesmo que o código dela seja diferente.
